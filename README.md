## Featured Projects

### JusTraduz

Legal-tech academic project built with PHP, MySQL, HTML, CSS and vanilla JavaScript.

Focused on document interpretation, user dashboards, professional approval flows, LGPD-aware features, admin controls and a polished presentation experience.

**Main areas:** authentication, dashboards, document upload, user roles, approval workflow, audit logs and UX refinement.

### Zokyo

Technical assistance management system focused on service orders, clients, inventory, financial control and multi-tenant architecture.

Designed to support real repair-shop operations, including customer records, device data, service status, PDF generation and business management modules.

**Main areas:** backend architecture, database modeling, service orders, multi-tenant structure and operational automation.

### OAB/CNA Validation Flow

Internal validation flow using PHP, Flask, Playwright and MySQL to consult, process and store public lawyer registration data.

**Main areas:** API integration, browser automation, data persistence, validation rules and backend communication.
