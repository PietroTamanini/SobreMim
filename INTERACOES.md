# Recursos interativos

## Editor

- Troca de arquivos pelas abas ou ícones laterais.
- Clique em uma linha para adicionar ou remover um breakpoint.
- `Ctrl + Enter` executa o arquivo ativo no terminal.

## Terminal

Abra pelo ícone `>_`, pela tecla `/` ou por `Ctrl + \``.

Comandos disponíveis:

```text
help
whoami
about
projects
stack
contact
pwd
ls
clear
open github
open linkedin
open justraduz
open zokyo
open oab
filter all
filter python
filter php
filter docker
```

## Paleta de comandos

Use `Ctrl + K` para navegar rapidamente entre projetos, stack, contato, GitHub e LinkedIn.

## Projetos

Os filtros alteram a lista sem recarregar a página. Somente um projeto permanece expandido por vez.
